Core Technology Stack

Built on Modern, Proven Technologies

A lightweight, secure architecture designed for high-performance real-time legal operations.

✵
Frontend — Next.js + Tailwind CSS v4
React-based framework with Tailwind CSS v4 and Lucide Icons providing a modern, responsive, and user-friendly interface for dashboards and legal management modules.
🐍
Backend — FastAPI (Python)
Asynchronous routing and SQLAlchemy ORM enabling high-performance API development, efficient request handling, and scalable backend operations.
🗄
Database — MySQL
Configured with connection pooling, automated schema validation, and migration helper scripts ensuring reliable data storage and integrity during application startup.
🤖
AI Engine — Google Gemini API
gemini-flash-latest model integrated for AI-based legal document generation — drafts, pleadings, notices, and document assistance with client-side PDF export via jsPDF.
🔐
Security — JWT + Bcrypt
JWT authentication, Passlib/Bcrypt password hashing, and a dynamic role-based permission system supporting Client, Senior Advocate, and Junior Advocate roles with protected routes.
⚖
eCourts Integration
Architecture designed for eCourts India case retrieval using 16-character CNR numbers. Database schema and UI prepared; live API integration under research due to CAPTCHA challenges.
📅
Scheduler — APScheduler
Background worker performs scheduled daily checks and automatically sends responsive HTML email reminders to clients and advocates via Google SMTP at 5, 2, and 1-day intervals.
🐳
DevOps — Docker + Compose
Dockerized application with Dockerfile, docker-compose.yml, and docker-compose.dev.yml for simplified development, testing, and production deployment across multiple environments.

Three Core Workflows

How Legal-Tech Operates

End-to-end workflows that automate the full lifecycle of a legal case — from intake to hearing reminders.

1
Case Creation & Consultation Scheduling
From client intake to booked consultation
1
The Senior Advocate creates a new case by entering the client's information, case details, uploading relevant documents, and assigning the case profile within the system.
2
When a consultation is required, the Senior Advocate or Client schedules it by selecting a preferred mode — Video Call, Face-to-Face Meeting, or WhatsApp Chat.
3
The system supports booking, rescheduling, and status updates while automatically synchronizing the calendar and dispatching notifications to all relevant users.
2
Case Assignment & Hearing Management
Assigning work and synchronizing schedules
1
The Senior Advocate registers a case, assigns the client, uploads case documents, and records hearing details and important case information into the system.
2
The case is assigned to a Junior Advocate with specified assignment details, priority level (High, Medium, or Low), and work instructions.
3
The assigned case is automatically reflected in the Junior Advocate's dashboard, hearing schedules sync to the calendar, and the notification system activates for efficient tracking.
3
Automated Hearing Reminders & Notifications
APScheduler-driven email reminders at 5, 2, and 1 day intervals
1
The Senior Advocate updates hearing dates, case status, and important information through the Case Management dashboard.
2
The APScheduler background service performs scheduled daily checks to identify upcoming hearings and important case milestones across all active cases.
3
The system automatically sends responsive HTML email notifications to the registered client and assigned Junior Advocate at 5-day, 2-day, and 1-day intervals before every scheduled hearing via Google SMTP.
